# 42Lisboa Minishell

Welcome to **Minishell**, a 42Lisboa project where you build your very own UNIX shell from scratch!  
This repo is a hands-on journey into the world of process management, parsing, and terminal magic.

## 🚀 What is Minishell?
Minishell is a simplified shell application, designed to mimic the behavior of Bash. It accepts, parses, and executes user commands, handling pipes, redirections, environment variables, and more — all written in C for performance and learning.

## ✨ Features
- **Execute commands**: Run binaries with arguments like a pro.
- **Pipes & Redirections**: Connect commands and manage input/output easily.
- **Environment variable management**: Export, unset, and use env variables.
- **Built-in commands**: Implement your own `cd`, `echo`, `exit`, etc.
- **Signal handling**: Graceful handling of interrupts and signals.

## 🤓 Why is this project cool?
Building Minishell is like peeking behind the curtain of your operating system. You’ll discover:
- How shells parse and interpret input
- The art of process creation and management
- Tricks for handling user input and output

## 📚 Learning Outcomes
- Deepen your understanding of UNIX internals and the C language
- Master system calls like `fork`, `execve`, and `wait`
- Learn robust error handling and memory management

## 🛠️ Getting Started
Clone the repo and run `make` to build your own shell.  
Read the code, tinker with the features, and make it your own!
